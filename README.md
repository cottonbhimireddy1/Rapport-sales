# Rapport-sales
Sales analysis over 30 stores of rapport gust services
This repository contains an Advanced Excel practice workbook that demonstrates the application of data analysis and reporting techniques using Microsoft Excel. The project focuses on organising, analysing, and visualising data to support effective decision-making.

It includes the use of advanced Excel functionalities such as formulas, functions, data cleaning, pivot tables, and data visualisation tools. The work highlights the ability to transform raw data into structured insights through efficient spreadsheet design and analytical thinking.

This project reflects practical skills in handling datasets, building dynamic reports, and presenting information in a clear and user-friendly format, showcasing proficiency in Excel as a key tool for data analysis.
